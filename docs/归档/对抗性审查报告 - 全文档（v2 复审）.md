## 3. 新发现

### 3.1 新 P0-1：`ImmutableFrame` 按值传递使引用计数失效

**定位**：S3 §2.3:185、§2.3:189-203、§7.1:465-467

**证据**

```go
type ImmutableFrame struct {
    Bytes []byte
    refs  atomic.Int32   // 值类型字段
    pool  *sync.Pool
}
func (f *ImmutableFrame) Release() { ... }

type P2Sender interface {
    TrySendBroadcast(frame ImmutableFrame) error   // 按值传参
}
```

扇出处：`err = ref.Sender.TrySendBroadcast(frame)`（S3 §7.1:467）。

**判定**：`ImmutableFrame` 是值类型，`atomic.Int32` 不是可复制类型。按值传入 `TrySendBroadcast` 时，`refs` 被**复制**成一份独立计数器：

- 队列副本 `Retain` 后计数为 2（副本自己的 0→1 或 1→2，取决于复制时点）；
- 扇出方对原值 `Release`，原计数归零 → `pool.Put(Bytes)`；
- 队列副本仍持有同一 `Bytes`，下一轮 publish 从池中取出并覆盖 → **跨帧串数据**；
- 副本计数永远无法归零 → buffer 永不归还（泄漏），`pool` 还会被重复 Put 同一块内存。

这正是 P0-3 要修的 bug，以"类型复制"的形式原样回来了。同时 `go vet` 会报 `passes lock by value`（`atomic.Int32` 内含 `noCopy`），直接违反 S0/S3 验收中的 `go vet` 项。

**影响**：内存安全缺陷（数据错乱）+ 池泄漏 + 静态检查阻断。比原 P0-3 更隐蔽，因为代码"看起来"用了引用计数。

**修复**（三选一，推荐 A）：

- A. 全链路改为指针：`TrySendBroadcast(frame *ImmutableFrame)`、`SharedEncoder.Encode(...) *ImmutableFrame`、`Retain/Release` 指针接收者；`refs` 保持值字段即可。
- B. `refs *atomic.Int32`，`pool *sync.Pool`，结构体仍可复制但计数与池共享。
- C. 放弃共享，每连接拷贝入队（需 ADR 记录 N 倍拷贝，删除引用计数）。

无论哪种，都必须补两条断言：`Release` 后计数不得为负（double-release 立即 panic）；`pool != nil` 才允许 Put。

## 4. 修订后仍需注意的两个系统性风险

1. **"对称性"成为新的检查盲区。**
   本轮修订在关键路径上补了守卫（`settle_message`、Version 解绑、引用计数），但都是"补了一侧"：结算有 CAS、过期没有；解绑有 Lua、绑定有 Lua（这次补齐了）、但绑定残留没有清理；引用计数有 `Retain/Release`、但类型按值复制。**审查方法应固定为"每条写路径都问：它的对立面是否有同等守卫"**，这比逐条对照契约更容易发现本轮这类问题。

2. **机制从"单实例"扩展到"多实例"时，旧假设未同步。**
   S7 的 DW 从 S2 的单 goroutine 变为多实例，但扫描 SQL 没有分片过滤；facts 从单 Relay 变为"单实例或并行"，但有序性仍按单实例写；S8 的重复上界仍按 Kafka consumer 写。**凡是"单 → 多"的演进点，都应单独列一张"并发维度表"（谁并行、按什么切分、顺序/幂等由什么保证）**，否则会反复出现这一轮 P1-2/3/5。

## 6. 复审结论

- v1 的 8 个 P0 中，**7 个的设计层面已闭环**；P0-3 的修复引入了新的类型级 P0，必须在写码前改掉。
- v1 的 16 个 P1 中，**15 个已闭环**；P1-9 的主结论（零丢失 + 有界重复）正确，但上界计算口径要按 DW 的模型重写。
- 新发现的 1 P0 + 7 P1 全部位于"修订新增的机制"附近，不属于原有缺陷回潮，说明本轮修订的方向是对的，缺的是**对称性检查**与**并发维度检查**。
- **建议**：完成批次 1–2 后即可冻结 S2 契约并开始 S0–S2 实现；批次 3 可在 S6 实现前完成，不影响前期进度。

> 一句话：文档已从"自相矛盾"进入"局部不对称"阶段；再补一轮对称性与并发维度审查，就可以作为实现基线。
