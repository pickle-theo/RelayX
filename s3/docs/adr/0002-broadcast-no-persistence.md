# ADR 0002：广播不落库、不进可靠状态机

- 状态：Accepted
- 背景：广播与可靠消息都涉及「送达」，容易误接入 S2 状态机。
- 决策：`POST /v1/broadcasts` 受理后直接内存扇出；不写 PostgreSQL、不产生 delivery、不参与 S2 重试/TTL/ACK。返回 202 = 已进入扇出，不代表送达。
- 理由：广播是连接级 Best-Effort 语义，断连即失效；落库会引入「谁清理订阅」的分布式问题，并混淆两种送达语义。
- 后果：离线订阅者收不到广播且不补发；可选幂等键只是 HTTP 层 30 秒内存窗口；S7 接 Kafka 时只换广播来源，不改扇出逻辑。
