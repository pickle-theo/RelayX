# ADR-0003：统一发送路径四通道与单 Writer

- 状态：Accepted（S1 LLD §4 冻结）
- 背景：S2 可靠消息、S3 广播、S4 客户端事件若各自实现发送逻辑，QoS 优先级
  与预算隔离会失效，慢消费者或广播洪峰会拖死心跳。这是架构方案 D5 的核心。

## 决策

- 每条连接一个 `SendPath`，内含四个物理隔离队列 P0–P3，各自帧数 + 字节双预算。
- 唯一 Writer goroutine 按 P0→P1→P2→P3 严格优先级取帧写 Socket；P0 绝对优先，
  心跳/关闭不被数据淹没。
- 满队列行为按通道固定：P1 `BlockAndDrain`（背压，超时 = 慢消费者断连）；
  P2 `DropAndCount`；P3 `DropLowPriority`。丢弃计入 `/metrics`。
- 通道数恒为四，术语恒为「四通道」，不得改写为其他数目（S5 隔离验收的前提）。
- 入站帧不经过 SendPath，不参与写队列预算。

## 后果

- S2/S3/S4 只需把新帧接入已有通道，不改发送骨架；S5 只优化实现、不改语义。
- 物理隔离保证一类帧打满不影响其他类；实测 `TestBudgetIsolation` 验证打满 P2
  不影响 P1 写出。
- 出站序号由 SendPath 在入队前分配，连接内单调不回绕（继承 S0），与入队顺序一致。
